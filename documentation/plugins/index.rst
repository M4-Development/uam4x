Plugins
=======

The public General, NDARC, OpenVSP, and IXGEN plugin packages are installed
with UAM4X from this repository. Their Python APIs are listed below. Solver
executables and their Python bindings still need to be installed separately
for examples that use them.

``LookupTablePlugin`` and ``DerivativeGroupGenerator`` are placeholders; their
API entries do not imply a working implementation.

.. toctree::
   :maxdepth: 1
   :caption: Public plugins

   general
   ndarc
   openvsp
   ixgen

CAMRAD II and M4SS are private integrations installed separately. Their pages
here describe their relationship to the public package; consult their private
repository for installation and API details.
